Jossie's 2522 project - CafeDash

Introduction:
The idea was to simulate what my job was like helping out the family restaurant back in the day.
My idea was bigger than the time I had. I think I will work on this in the summer time.
I like time management games, and it was nice to recreate a bit of my history for a spot of nostalgia.

Instructions:
- use WASD to move around
- use J to interact with objects in the game
- use I to see your current income
- Use P to save your income for the next time you play

Notes:
- This is a small portion of what the game could be.
- There are coupling issues that need to be addressed.
- Spotbugs and CheckStyles not completely cleared.

What I would do better in the next rendition:
- Figure out proper animation, as I have all the swinging pngs created, but did not use them all
- Polish the customer flow and interaction logic
- Improve furniture and collision handling structure (a bit sticky)
- Add more furniture types, menus, and a proper order system
